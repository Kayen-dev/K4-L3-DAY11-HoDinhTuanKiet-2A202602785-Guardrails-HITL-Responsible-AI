03 · Checkpoint 2

Input guard: chuẩn hóa trước, quyết định sau

Injection detection

  • NFKC và loại ký tự zero-width
  • Nhận diện override, roleplay, exfiltration, encoding
  • Bắt lệnh ẩn trong email hoặc tài liệu RAG
  • Nhận diện cả secret bị tách dấu
Ignore​ all previous instructions → normalize → injection signature → BLOCK before model

Topic policy

  • Allowlist nghiệp vụ banking bằng tiếng Anh và tiếng Việt
  • Blocked topic được ưu tiên trước allowlist
  • Benign external data vẫn được tóm tắt
  • Off-topic trả lời ngắn, không gọi model

05 · Checkpoint 3

Policy không dừng ở nội dung

Sliding-window rate limit

  • Theo từng user, không dùng counter toàn cục
  • Tự loại timestamp hết hạn
  • Trả thời gian chờ rõ ràng

Exact egress allowlist

  • Chỉ HTTPS và hostname VinBank chính xác
  • Chặn subdomain giả và embedded credential
  • Scan PII/secret trước khi gửi

Audit & monitoring

  • Request ID, layer, decision, latency
  • Block rate và rate-limit hit
  • Cảnh báo khi vượt threshold

Human-in-the-loop

  • Transfer, close account, change password
  • Approval ID + reviewer ID bắt buộc
  • Reject hoặc timeout đều fail-closed
